# INTRODUCCION
Este es el Front End del proyecto para un marketplace de Jesus Obispo y Jaume Puig.

# INSTALACION
Para instalarlo simplemente hay que descargar el proyecto e instalar las dependencias necesarias utilizando el package manager.

Para encender el servidor hay que utilizar npm run start.

# MIEMBROS
Jesus Obispo: Encargado principalmente de todo lo referente a los productos.
Jaume Puig: Encargado principalmente de todo lo referente a los usuarios.

# Miscelania
Para esta parte del proyecto hemos utilizado typescript como lenguaje de programacion, mongodb para la base de datos y utilizamos httpClient para conectarnos al back end.
